# Hi, I'm Matthew

Data scientist with an M.S. in Data Science from UC San Diego and a B.S. in Applied Mathematics from UC Santa Cruz. I build end-to-end analytics and machine learning projects, from data collection and feature engineering through modeling and clear communication of results.

I'm especially interested in clean energy and game analytics.

## Featured Projects

**[Three Houses Class Optimizer](https://github.com/mam084/three-houses-optimizer)**
Interactive Streamlit tool that recommends Fire Emblem: Three Houses class paths and teams, using scraped game data, cosine-similarity role detection, constraint-aware class scoring, and stat simulation. 230+ tests and CI.

**[Steam Game Success Prediction](https://github.com/mam084/steam-game-success-prediction)**
Predicts whether a game will be well received using only launch-time metadata, with review data kept out of the inputs to avoid leakage. TF-IDF + scikit-learn pipelines reach ~0.80 ROC AUC on a held-out test set.

**[Emissions Explorer](https://github.com/mam084/Emissions_Explorer)** · [live](https://mam084.github.io/Emissions_Explorer/)
Interactive D3 visualization of quarterly greenhouse gas emissions by region, sector, and gas (IMF data, 2010–2025), with careful handling of overlapping totals in the source data.

**[Amazon Review Sentiment & Economic Trends](https://github.com/mam084/amazon-sentiment-economic-trends)**
Team project using a PySpark NLP pipeline on ~30 GB of Amazon reviews to test whether consumer sentiment tracks U.S. GDP growth.

**[ASL Sign Recognition](https://github.com/mam084/asl_recognition)**
PyTorch CNN and CNN-LSTM models for word-level sign recognition from video, evaluated on signers the model has never seen.
